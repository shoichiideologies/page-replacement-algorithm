Memory Management Notes

Page-Replacement Algorithms

In modern computing, efficient memory management is critical for performance. One important technique is demand paging, where only the necessary parts of a program are loaded into memory as needed. However, when memory becomes full, the operating system must decide which page to remove to make space for a new one. This decision is made using page-replacement algorithms.

First-In-First-Out (FIFO)

Queue based

First-In, First-Out (FIFO) is one of the simplest page replacement algorithms. It works exactly like a queue: the oldest page in memory, the one that was loaded first, is the first to be removed when space is needed for a new page. While FIFO is easy to implement and understand, it may remove pages that are still being used frequently, which can increase the number of page faults. This algorithm is also known to suffer from Belady's anomaly, where adding more memory can unexpectedly lead to worse performance.

Time complexity: O(n) per operation (naive), O(1) with hash for lookup plus queue.

Space complexity: O(n).

Least Recently Used (LRU)

History based

Least Recently Used (LRU) is a smarter page replacement algorithm that tries to guess which pages are no longer needed. It removes the page that has not been used for the longest time, based on the idea that pages used recently are more likely to be used again soon. LRU is more efficient than FIFO in many real-world situations, especially when programs tend to reuse data shortly after accessing it.

Time complexity: O(n) (naive), O(1) optimized with HashMap plus Doubly Linked List.

Space complexity: O(n) frames plus O(n) recency metadata.

Optimal (OPT)

Future based

Optimal Page Replacement (OPT) is a theoretical algorithm that always makes the best possible choice by replacing the page that will not be used for the longest time in the future. It achieves the fewest possible page faults for any given reference string and number of page frames. Since no real system can predict future memory accesses, OPT is mainly used as a benchmark to compare the performance of other algorithms like FIFO and LRU.

In cases where two or more pages in memory will not be used again, all of them are valid candidates for replacement. In this simulator, the algorithm selects the first-found page among them because it is consistent, predictable, and fast to compute.

Time complexity: O(n) per replacement because it scans the future reference string.

Space complexity: Requires full future knowledge, so it is only usable as a benchmark.

Glossary of Terms

Reference

Page: A fixed-size block of memory used in virtual memory systems. Pages are loaded into frames for program execution.

Belady's Anomaly: A situation where adding more memory results in more page faults under certain algorithms like FIFO.

Time Complexity: Describes how the running time of an algorithm scales with input size.

Space Complexity: Describes how much memory an algorithm uses relative to input size.

First-Found: A method that selects the first available option, often for simplicity and consistency.

Random Selection: A method that chooses an option randomly from valid candidates.

Demand Paging: A strategy where pages are loaded into memory only when needed.

Naive: A basic or unoptimized approach to solving a problem.

Queue: A First-In, First-Out data structure where the first item added is the first removed.

Linked List: A sequence of nodes where each node points to the next, allowing dynamic memory usage.

HashMap: A key-value data structure that allows constant-time data access using hashes.

Metadata: Information that describes or gives context to other data.

Frames: Fixed-size memory slots that hold pages during program execution.

Reference String: A sequence showing the order in which memory pages are accessed.

Benchmarking: Evaluating algorithms by comparing performance metrics on standard inputs.

O(n): Linear time complexity, where processing time grows with input size.

O(1): Constant time complexity, where operations take the same time regardless of input size.
